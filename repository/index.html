somepanic Kodi repository

Plex, Jellyfin, Silo and YouTube for Kodi 21 and 22 on CoreELEC, from one repository that keeps them up to date.

{{repository_zip}}

Install in Kodi

  1. Open Settings → System → Add-ons and turn on Unknown sources.
  2. Open Settings → File manager → Add source, enter https://somepanic.github.io/ and name it somepanic.
  3. Open Add-ons → Install from zip file → somepanic and choose the repository zip.
  4. Open Add-ons → Install from repository → somepanic and pick an add-on or skin.

Kodi reads the list for its own version: Kodi 21 (CoreELEC 21, 32-bit ARM) or Kodi 22 (CoreELEC 22, 64-bit AArch64). Leave automatic updates on to get each new release.

Already installed one of these from a zip? Open its add-on information, choose Versions, and pick the version from somepanic to get updates. Your settings stay in place.
